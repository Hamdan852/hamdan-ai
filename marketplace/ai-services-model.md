# Hamdan AI Services Marketplace

## Product model

Hamdan combines an AI development engine with a future global services marketplace. Companies can submit AI/software requirements; Hamdan can scope the work, recommend an execution path, and route delivery to Hamdan AI agents, approved human specialists, or a hybrid team.

## Service categories

- AI website and web-app development
- AI agents and chatbots
- Customer-support automation
- Voice and conversational AI
- Video, image and audio generation
- Business-process automation
- AI API and SaaS integrations
- Data processing and analytics
- AI marketing systems
- Custom AI software

## Client workflow

1. Submit requirement
2. AI requirements analysis
3. Clarification questions
4. Scope and acceptance criteria
5. Estimate and proposal
6. Client approval
7. AI-only, human-only, or hybrid execution
8. Automated testing and quality review
9. Client review and revisions
10. Delivery and deployment
11. Support and maintenance

## Provider model

Providers should have profiles, capabilities, portfolio evidence, availability, rates, ratings, verification status and delivery history. AI agents should expose equivalent capability metadata so the routing system can compare execution options.

## Routing principles

- Prefer Hamdan automation when it can meet the acceptance criteria reliably.
- Escalate to a verified specialist when the task requires human judgment, credentials, access or domain expertise.
- Use hybrid execution when AI can accelerate implementation while a specialist handles review or domain-specific work.
- Never claim a job is completed until its acceptance checks pass.

## Marketplace safety

Payments, contracts, identity verification, dispute handling, refunds, taxes and provider compliance must be implemented with appropriate third-party infrastructure and legal review before production launch.

## Initial MVP

The first marketplace release should support: client project intake, AI scope generation, service-category matching, proposal generation, project workspace, status tracking, provider profiles, and links into Hamdan Developer for automated delivery.
