SECURITY

Safe-by-design developer actions

  • Server-side secretsNever expose API keys in browser code.
  • Least privilegeGive connectors only the permissions needed for the task.
  • Approval gatesRequire authorization before consequential writes or deployments.
  • Audit trailRecord what Hamdan planned, changed and verified.
  • Truthful statusNever report a change as complete before it is actually verified.
